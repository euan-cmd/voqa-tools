# Voqa x Kelvelec EV range calculator

Jointly branded calculator showing how fast different chargers add range to an EV.

Starts from `/ev-charging/` (v1.1.0). Planned fixes: per-vehicle max AC charge rate, per-model usable battery sizes, charging losses, DC taper above ~80%.

Work in progress on the `kelvelec-range` branch. Not live until merged to `main`. Kelvelec branding to be approved by Kelvelec before merge.
